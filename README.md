# 📱 Phone Management System

A Python-based Phone Management System built using Object-Oriented Programming (OOP). This project simulates the core features of a real smartphone while focusing on clean code, modular design, and step-by-step project development.

## ✨ Current Features

* 📞 Call Management

  * Make calls
  * View recent call history
  * Search recent calls
* 👥 Contact Management

  * Add contacts
  * View contacts
  * Search contacts
  * Delete contacts
* 💬 Message Management

  * Send messages
  * View message history
  * Delete messages
* 🔋 Battery Simulation

  * Battery usage
  * Battery charging
* 🎵 Entertainment

  * Music player
* 🧮 Calculator *(In Progress)*

  * Addition
  * Multiplication
  * More operations coming soon

## 🚀 Upcoming Features

* Complete calculator operations
* Improved entertainment section
* App-style menu navigation
* File handling for data persistence
* Additional real-world phone features
